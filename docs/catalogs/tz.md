Решения Andriy 29.10, 04.11 и 11.11.2026: `catalogs/decisions.md` (внутренний файл, в репозитории нет). Проверочная таблица с формулами: `catalogs/catalog-price-check.xlsx` (внутренний файл, в репозитории нет) (в ней примеры T01–T03; остальные тесты §10 посчитаны по той же формуле и перепроверены независимым скриптом). Журналы, брошюры и каталоги — один продукт и одна страница. На сайте он называется «Каталоги и журналы» / «קטלוגים ומגזינים».

## 1. Продукт

| Параметр | Варианты |
|---|---|
| Формат (вертикальный, обрезной) | A4 (210×297), A5 (148×210), A6 (105×148) |
| Переплёт | скоба (2 скобы по корешку) или металлическая спираль (белая) |
| Блок | всегда цвет с двух сторон (4+4) |
| Бумага блока | 80 г офсет; 130 / 170 / 250 / 300 г мелованная **матовая** (глянцевой нет) |
| Отдельная обложка | да / нет. «Нет» означает самообложку: первая и последняя страницы блока |
| Бумага обложки | 250 / 300 г мелованная матовая |
| Печать обложки | 4+0 (только снаружи) или 4+4 |
| Ламинация обложки | нет / матовая / глянцевая (цена одна), только снаружи; доступна только при отдельной обложке |
| Тираж | целое число от 6 до 100 000 (выше — `qty_max`) |
| Срок | до 7 рабочих дней |
| Получение | только самовывоз (ул. Штампфер 5, Нетания); оплата вне сайта |

Клиент вводит **число страниц блока без обложки**. Отдельная обложка всегда 4 страницы (лицо, оборот лица, оборот задней, задняя).

## 2. Ограничения по страницам

| Переплёт | Шаг | Минимум | Максимум страниц блока по бумаге блока |
|---|---|---|---|
| Скоба | 4 | 8 без обложки; 4 с обложкой | 80 и 130 г: 36 · 170 г: 24 (обложка не входит) · 250 г: 12 вместе с обложкой, то есть без обложки 12, с обложкой 8 стр. блока (обложка = 4 стр.) · 300 г: нельзя (`bad_paper`, см. §11) |
| Спираль | 2 (см. §11) | 20 | 80 г: 200 · 130 г: 150 · 170 г: 120 · 250 и 300 г: 60 |

Пример: скоба, 250 г, без обложки — 8 или 12 стр.; с обложкой — 4 или 8 стр. блока (всего с обложкой не больше 12). Скоба, 170 г: до 24 стр. блока (обложка в это число не входит).

Сервер проверяет каждое ограничение и при нарушении возвращает ошибку (см. §5). На странице нельзя выбрать недопустимое: поле страниц меняет шаг, min и max при смене переплёта, бумаги и обложки; если текущее значение выходит за новые пределы, оно приводится к ближайшему допустимому (вниз к max, вверх к min, к кратному шагу). Если значение поменялось из-за смены бумаги, переплёта или обложки, под полем пишется, что и почему: «Для {бумага} со {переплёт} максимум {max} стр. — исправили {old} → {new}.» (так же для минимума и шага). При загрузке страницы и при восстановлении по «Назад» пояснение не показывается. Пункт «300 г» для блока при скобе неактивен; если он был выбран и клиент переключил переплёт на скобу, выбирается 250 г.

### 3.2. Формула

Обозначения: q — тираж, n — страниц блока, g — бумага блока, cg — бумага обложки, f — формат. Все суммы в `decimal`; ⌈a/b⌉ — деление с округлением вверх (`Math.Ceiling((decimal)a / b)` или `(a + b − 1) / b` на `long`), не целочисленное деление. Все числа ниже берутся из конфига по ключам §3.1, в коде их нет.

1. Листов блока на тираж: `S_b = ⌈q × n / PagesPerSheet(f)⌉`.
2. Блок: `C_b = S_b × (SheetPrice(g) + 2 × ClickColorIls)`.
3. Если есть обложка: `S_c = ⌈q / CoversPerSheet(f)⌉`; иначе `S_c = 0`.
4. Обложка: `C_c = S_c × (SheetPrice(cg) + k × ClickColorIls)`, k = 1 для 4+0, 2 для 4+4.
5. Ламинация (только при обложке): `C_l = S_c × LaminationUsdPerM2 × UsdRateIls × SheetAreaM2`, иначе 0.
6. Толщина экземпляра: `T = n/2 × ThicknessMm(g) + (обложка ? 2 × ThicknessMm(cg) : 0)`.
7. Переплёт, материалы:
   - скоба: `C_m = q × StaplesPerCopyIls`;
   - спираль: первая спираль по возрастанию, у которой `T ≤ MaxThickness`; если ни одной, то ошибка `too_thick`. `C_m = q × SpiralPrice × SpiralLengthFactor(f)`.
8. Работа (только спираль): ударов на экземпляр `U = ⌈(n/2) / SheetsPerPunch(g)⌉ + (обложка ? ⌈2 / SheetsPerPunch(cg)⌉ : 0)`; `C_w = q × (U × PunchSec + SpiralCloseSec) / 3600 × LaborRateIlsPerHour`. Для скобы `C_w = 0`.
9. Себестоимость: `C = C_b + C_c + C_l + C_m + C_w`.
10. С браком: `C' = C × (1 + WasteRate)`. C′ не округляется.
11. Наценка на всю сумму: `K = MarkupLow`, если `C' < MarkupThresholdIls`, иначе `K = MarkupHigh` (порог сравнивается с C′, то есть с браком; см. §11).
12. Цена без НДС: `P = max(MinOrderIls; round(C' × K; 2))`. Флаг `minApplied = true`, если сработал минимум.
13. Если `P > MaxAutoPriceIls` (строго больше; ровно 2000,00 — ещё автоцена), автоцены нет: ответ `manual_quote` без сумм, на странице текст «Рассчитаем индивидуально» и кнопка WhatsApp с параметрами без цены.
14. НДС: `V = round(P × VatRate; 2)`; цена с НДС `P + V` (внутренняя, клиенту не показывается). Итог для клиента: `Total = round(P + V; 0)` — целые шекели, к ближайшему, .50 вверх (1346,19 → 1346). За экземпляр: `round(Total / q; 2)` (1346 / 100 = 13,46).

Округление только в шагах 12 и 14, `MidpointRounding.AwayFromZero`.

Следствие правила наценки (подтвердить, §11): на пороге цена падает — T10: 78 шт. 988,72 ₪, T11: 79 шт. 901,26 ₪.

## 5. API

`POST /catalogs?handler=Calculate` (как `stickers.cshtml.cs`, с antiforgery). Запрос:

```json
{ "format": "A4", "binding": "staple", "pages": 12, "blockPaper": 130,
  "hasCover": true, "coverPaper": 250, "coverPrint": "4+4",
  "lamination": "none", "quantity": 100 }
```

`binding`: `staple|spiral`; `coverPrint`: `4+0|4+4`; `lamination`: `none|matte|gloss`. При `hasCover=false` поля `coverPaper`, `coverPrint`, `lamination` не проверяются и в расчёт не идут.

Ответ при успехе: `{ "success": true, "status": "ready", "data": { "priceExVat", "vat", "priceIncVat", "totalIncVat" (целые ₪, это показывают страница и сообщение), "pricePerCopyIncVat" (= round(totalIncVat / q; 2)), "minApplied", "spiralMm" }, "wpmessage": "<готовый URL wa.me>" }`. `spiralMm` для скобы `null`.
`manual_quote`: `{ "success": true, "status": "manual_quote", "wpmessage": "…" }` — без сумм.
Ошибка: `{ "success": false, "errorCode": "…" }`, HTTP 400. Проверки идут в этом порядке, возвращается первый сработавший код:
`bad_request` (поле отсутствует, не число, дробное, не тот тип) → `bad_format` → `bad_binding` → `bad_paper` (бумага блока не из списка или запрещена для переплёта, например 300 г при скобе) → `bad_cover` (при обложке: бумага не 250/300, печать не 4+0/4+4) → `bad_lamination` (при обложке) → `pages_step` → `pages_min` → `pages_max` → `qty_min` → `qty_max` → `too_thick`.
Любое значение не из списков → ошибка, а не значение по умолчанию. Тексты ошибок в resx на двух языках.

Сервис расчёта — отдельный класс (`CatalogCalculatorService`, singleton) с юнит-тестами T01–T13 и V01–V16.

## 6. Сообщение WhatsApp

Собирает сервер, ссылка `https://wa.me/<номер>?text=` + `Uri.EscapeDataString(текст)` (без фигурных скобок вокруг номера, ошибка визиток). Номер — общая константа. Цена — итог в целых шекелях: `1346 ₪`, в иврите обёрнута в LRM. Строки НДС нет.

```text
Здравствуйте! Хочу заказать каталог.
Формат: A4, скоба

Обложка: мелованная матовая 250 г, печать 4+4, без ламинации
Количество: 100 шт.
Цена: 1346 ₪ с НДС
Файл макета пришлю следом через 📎 → «Документ» (не «Галерея»).
```

```text
שלום! אני רוצה להזמין קטלוג.
גודל: A4, סיכות
פנים: 12 עמ׳, כרומו מט 130 גרם
כריכה: כרומו מט 250 גרם, הדפסה 4+4, ללא למינציה
כמות: 100 יח׳
מחיר: 1346 ₪ כולל מע״מ
את קובץ ההדפסה אשלח מיד דרך 📎 ← "מסמך" (לא "גלריה").
```

Варианты строк: переплёт «скоба / спираль» — «סיכות / ספירלה»; бумага 80 г «офсет 80 г» — «אופסט 80 גרם», остальные «мелованная матовая {g} г» — «כרומו מט {g} גרם» (и в строке блока, и в строке обложки, с маленькой буквы); без обложки строка «Обложка: без отдельной обложки» — «כריכה: ללא כריכה נפרדת»; ламинация «ламинация матовая / глянцевая» — «למינציה מט / מבריקה». При `manual_quote` строка цены заменяется на «Прошу рассчитать цену» / «אבקש הצעת מחיר».

## 7. Требования к макету (по умолчанию как у визиток, подтвердить)

- Один многостраничный PDF, страницы по порядку, обложка отдельным PDF (если есть).
- Размер страницы = формат + вылеты 2 мм с каждой стороны (A4: 214×301 мм).
- 300 dpi, безопасная зона 3 мм от реза.
- Для спирали дополнительно 8 мм от корешка без текста.
- Нет макета — напишите нам.

## 8. Чего нет в этой версии

Клеевой переплёт (КБС), твёрдая обложка, ч/б печать, глянцевая мелованная бумага, свой формат, горизонтальные форматы, доставка, оплата на сайте, загрузка файла на сайт.

## 9. Технические требования (уроки визиток)

1. Цена и проверка только на сервере; JS в `wwwroot/js/catalogs.js`, без inline-скриптов (CSP), тексты через `data-*`.
2. Все тексты в `Resources/Pages/Catalogs.{he,ru}.resx`, без заглушек в квадратных скобках.
3. Числа в форме и в API — инвариантная культура (`InvariantDecimalModelBinder`), на `/ru` тоже.
