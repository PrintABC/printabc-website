## П.3 Ошибка далеко под полем — подтверждено Andriy 2026-11-13

**Что не так.** Неподходящее число страниц (например 7) → текст ошибки появляется внизу, под полем «Количество». На телефоне его не видно, клиент не понимает, почему пропала цена. На 841b906 проблема осталась.

**Где менять.** Только `Pages/Catalogs.cshtml`, тексты ошибок не трогаем.
1. Блоки `<div class="alert alert--error" data-error="...">` сейчас стоят подряд после поля «Количество» (стр. 182–254). Переставить:
   - `pages_step`, `pages_min`, `pages_max`, `too_thick`, `bad_paper` → внутрь `<div class="field">` поля страниц, сразу после `<p id="pages-hint">` (стр. 119);
   - `qty_min` → внутрь поля количества, после `<p id="q-hint">` (стр. 180).
2. Скрипт:
   - стр. 503: `targetError.hidden = false;` → `showError(targetError);`
   - новая функция (показывает ошибку и красит рамку поля):
```js
function showError(alert) {
    alert.hidden = false;
    const input = alert.closest('.field')?.querySelector('input');
    input?.setAttribute('aria-invalid', 'true');
}
```
   - `hideAllErrors()` (стр. 406) — дополнительно сбрасывать `aria-invalid="false"` у `#calc-pages` и `#calc-qty`.

**Проверка.** Телефон, /ru/catalogs, 7 страниц → красная рамка и ошибка прямо под полем. Тираж 0 → ошибка под полем тиража.

## П.4 Пустое поле или 5.5 — цена пропадает молча — подтверждено Andriy 2026-11-13

**Что не так (есть на 841b906).** Стёр страницы/тираж или ввёл тираж 5.5 → цена пропадает без сообщения и появляется «Рассчитаем индивидуально». Сервер отдаёт код `generic` (`Catalogs.cshtml.cs:51-52`), а блока для него на странице нет.

**Про локализацию.** Всё тем же способом, что сейчас: сервер возвращает только код ошибки, текст страница берёт из resx через `@L["error_..."]` (как `error_qty_min`). В коде текстов нет.
1. `Catalogs.cshtml.cs:49-53` — смотреть, что клиент ввёл (`ModelState[key]?.AttemptedValue`): пусто или 5.5 → `qty_int`; 0, −5 → `qty_min`; пустые страницы → `pages_int`. Код — задание 11.11, п.4 (нужен `using System.Globalization;`).
2. `Catalogs.cshtml` — 3 блока ошибки по образцу существующих: `pages_int` (под полем страниц), `qty_int` (под тиражом), `generic` (над ценой). Код без своего блока → показывать `generic`. При ошибке «—», не «Рассчитаем индивидуально».
3. resx ru/he, новые ключи (иврит черновой, носителем не проверен):
   - `error_pages_int`: «Введите число страниц целым числом, например 12.» / «הזינו מספר עמודים שלם, למשל 12.»
   - `error_qty_int`: «Введите тираж целым числом, от 6 шт., например 100.» / «הזינו כמות במספר שלם, מ-6 יח׳ ומעלה, למשל 100.»
   - `error_generic`: «Проверьте значения в форме: с ними цену посчитать нельзя.» / «בדקו את הערכים בטופס: איתם אי אפשר לחשב מחיר.»

**Проверка.** Стереть страницы → ошибка под полем, красная рамка. Тираж 5.5 / пусто → «Введите тираж целым числом…». Тираж 0 → «Минимальный тираж — 6 шт.». «Рассчитаем индивидуально» не появляется.
