## 3. Новые проблемы (появились в 08928ec)

**Н-1 [сломано]. Тираж больше 100 000 → «null₪», кнопка активна и ведёт на `undefined`** (сайт he/ru, `05-ru-qty100001-null.png`)
- Что не так: сервер теперь правильно отвечает `qty_max`, но блока `data-error="qty_max"` на странице нет. В JS (cshtml:561) проверка `targetError || errorCode == "generic"` не срабатывает → код идёт в ветку «valid results» (:570-578): «Итого null₪», «0.00₪», кнопка зелёная, `href="undefined"`. Так же будет с любым кодом ошибки без своего блока.
- Как исправить: решать по статусу, а не по коду; код без блока → generic. Плюс блок `qty_max` под тиражом (ключ `error_qty_max`, ru «Максимальный тираж — 100 000 шт. Для большего тиража напишите нам в WhatsApp.», he — перевести).
  ```js
  const isError = result.data.status == "validation_error";
  const targetError = isError
      ? (form.querySelector(`[data-error="${result.data.errorCode}"]`) ?? form.querySelector('[data-error="generic"]'))
      : null;
  ...
  else if (isError) { toggleInvalidPrices(false); showError(targetError); setSend(false); ... }
  ```

**Н-2 [сломано]. Строка «в т. ч. НДС» показывает неверное число**
- Что не так: убрали `vatOutput.textContent = result.data.vatIls`, но саму строку (cshtml:316-319) оставили. Теперь при загрузке там заглушка «205.35 ₪» для любого выбора (без обложки: «Итого 1133₪, в т. ч. НДС 205.35 ₪», настоящее 172.76 — `03-ru-nocover-vat.png`), а после первой ошибки навсегда «—».
- Как исправить: удалить строку НДС (cshtml:316-319) и все `vatOutput` (:447, :567, :585) — как и просили в п.8.1.

**Н-3 [сломано]. Сырой ключ `order_minimum_hint`** (`04-ru-qty6-raw-key.png`, he так же)
- Что не так: теперь строка показывается при `minApplied` (тираж 6 → 118₪), но ключа нет ни в ru, ни в he resx.
- Как исправить: добавить ключи — ru «Минимальный заказ 118 ₪ с НДС», he «מינימום הזמנה — 118 ₪ כולל מע״מ» (answers п.8.5).

**Н-4 [частично новое]. После manual_quote ошибка видна рядом с «Рассчитаем индивидуально»** (`02-ru-manual-then-error.png`)
- Что не так: в ветке ошибки (cshtml:561-569) больше нет `toggleInvalidPrices(...)`; если до этого был manual_quote, блок manual остаётся, а блок generic внутри скрытого `#valid_prices` не виден.
- Как исправить: в ветке ошибки первой строкой `toggleInvalidPrices(false);` (входит в код Н-1).

Мелочь: в новом блоке generic номер телефона вписан в ссылку (cshtml:310 `https://wa.me/972508494172`), как и в других блоках ошибок; лучше `https://wa.me/@(PHONE_NUMBER)`.
