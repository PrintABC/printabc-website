3) ПРОБЛЕМЫ
Б (блокирующие визуально)
Б1. Нет CSS превью брошюры.
 Что не так: ни одного класса cat-* в wwwroot/css; превью — голый текст (vis-live-he-1366.png, vis-live-ru-390.png).
 Почему важно: ТЗ §4 прямо требует превью, которое меняет пропорции по формату A4/A5/A6; это главный «вау» блок макета.
 Как исправить: перенести из макета design/mockup/assets/css/pages.css строки 297-346 (.cat-cover-opts, .cat-summary, .cat-preview*, .cat-book*, мобильные размеры @media) в wwwroot/css/pages.css. Проверить, что токены --c-cyan, --c-yellow, --c-surface, --r-xl, --shadow-float, --font-head есть в tokens.css (если нет, взять из макета assets/css/tokens.css). Также JS должен ставить data-fmt/data-binding/.cat-book--gloss и заполнять [data-chips], [data-cover-sub] — на живом сайте JS (inline, cshtml:394+) это, по-видимому, не делает; в макете это в assets/js (искать cat-book) [предположение, код JS не сравнивал построчно]. Сверить с wwwroot/js: catalogs.js в репозитории нет, а ТЗ §9.1 требует wwwroot/js/catalogs.js без inline-скриптов.
Б2. Нижняя панель на телефоне не та.
 Что не так: _BottomBar.cshtml:2 жёстко «calculate_stickers» → /stickers.
 Почему важно: ТЗ §4: «Итого … Заказать →», параметр страницы, не жёстко /stickers.
 Как исправить: сделать _BottomBar параметризованным (ViewData["BottomBar"] уже передаётся в _Layout:32), для каталогов взять разметку из макета he/catalogs.html:176: .bottom-bar__price (label «Итого» + <output data-bar-total>), кнопка data-bar-ok «Заказать →» (href = wpmessage), data-bar-fix «Исправить параметры» при ошибке. CSS: layout.css:102-104 уже есть. JS должен обновлять data-bar-total при пересчёте.
В (важные)
В1. Формат цены. JS пишет result.data.priceIncVatIls + '₪' (Catalogs.cshtml:513) — без пробела и без LRM, а НДС/цена за шт. (514-515) вообще без ₪. После первого пересчёта вид меняется с «1346.19 ₪» на «1346.19₪». ТЗ §4/§6: формат «1346.19 ₪». Исправить: '‎' + value.toFixed(2) + ' ₪' + '‎' для всех трёх полей (как в серверной разметке cshtml:264-272). Следить за 2 знаками (13.5 → 13.50).
В2. Группы «Печать обложки»/«Ламинация» слиплись (нет .cat-cover-opts gap:22px) — решается тем же переносом CSS (Б1).
В3. Бумага 300 г при скобе не помечена disabled (серый зачёркнутый чип в макете). ТЗ §2: «нельзя выбрать недопустимое». Проверить в JS, что у radio ставится disabled и класс; стиль из макета (chip disabled).
