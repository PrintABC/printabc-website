# Текст WhatsApp-сообщения для визиток (варианты, 25.10.2026)

Основа: шаблон наклеек из docs/whatsapp-order/tz.md, §6.1 (без даты и кода заказа, решение от 22.10.2026; цена справочная). Пример: 500 шт., двусторонние, матовая ламинация, без скругления: 230 + 60 = **290 ₪**. Цену в коде форматировать как у наклеек: `290.00 ₪` в LRM.

## Вариант A: как у наклеек, строка на параметр (рекомендую)

```text
Здравствуйте! Хочу заказать визитки.
Формат: 9×5 см, мелованная матовая 350 г
Печать: Двусторонняя
Количество: 500 шт.
Отделка: Ламинация матовая
Цена: 290 ₪ с НДС
Файл макета пришлю следом через 📎 → «Документ» (не «Галерея»).
```

```text
שלום! אני רוצה להזמין כרטיסי ביקור.
גודל: 9×5 ס״מ, נייר כרומו מט 350 גרם
הדפסה: דו־צדדית
כמות: 500 יח׳
גימור: למינציה מט
מחיר: 290 ₪ כולל מע״מ
את קובץ ההדפסה אשלח מיד דרך 📎 ← "מסמך" (לא "גלריה").
```

Строка «Отделка» по опциям:
| Выбрано | RU | HE |
|---|---|---|
| ничего | Без отделки | ללא גימור |
| ламинация | Ламинация матовая / глянцевая | למינציה מט / מבריקה |
| скругление | Скруглённые углы | פינות מעוגלות |
| обе | Ламинация матовая, скруглённые углы | למינציה מט, פינות מעוגלות |
