# ТЗ: раздел «Бухгалтерские книжки» / «פנקסים» (v1.0, 13.11.2026)

**v1.0 (13.11.2026):** все 10 вопросов v0.2 закрыты владельцем, решения в `pinkasim/decisions.md` (внутренний файл, в репозитории нет). Общие правила для всех страниц: цены клиенту с НДС, целыми ₪, строки НДС нет; заказ одной кнопкой WhatsApp без кода заказа, сайт не хранит файлы (`process/2026-11-12-owner-decisions.md`, внутренний файл).

Источник цен и описания: старый сайт https://printabc.co.il/Category/Pinkasim и https://printabc.co.il/ru/Category/Pinkasim (05.11.2026). Образец механики: визитки (`docs/business-cards/tz.md`): фиксированная таблица цен, клик по ячейке. Ошибки и API — как у каталогов (`docs/catalogs/tz.md` §5). Отдельного макета в прототипе нет: страница строится по образцу страницы визиток (`Pages/Business-cards.cshtml`, `wwwroot/js/cards.js`) с текстами из §8.

## 1. Продукт

- Книжки квитанций, счетов, заказ-нарядов на самокопирующей (химической) бумаге.
- В каждой книжке **50 комплектов**. Других количеств комплектов на сайте нет (решение 05.11).
- Комплект из **3 листов**: оригинал белый + копии розовая и жёлтая, или из **2 листов**: оригинал белый + копия жёлтая. Клиент выбирает.
- Печать **только чёрно-белая** (цветную на сайте не показываем, решение 05.11).
- Квитанции **пронумерованы** и **перфорированы** для отрыва. Стартовый номер клиент пишет в WhatsApp; на сайте поля нет.
- Сборка: скрепление **скобой**, **картонная обложка**.
- Два вида:
  - **A5**: бланк 14,8 × 21 см.
  - **«Шестёрки»**: 6 бланков на листе A4, бланк **10,5 × 9,9 см**.
- Макет: свой файл клиента или вёрстка нами **бесплатно** по логотипу и реквизитам клиента.
- Срок: **до 3 рабочих дней**.
- Получение: **только самовывоз**, ул. Штампфер 5, Нетания, бесплатно. Доставки нет.
- Оплата вне сайта: наличные, карта, Bit или перевод.

## 2. Таблица конфигурации (единственный источник значений)

Все значения лежат в `appsettings.json`, секция `Pinkasim`, и меняются без программиста. В коде и JS чисел нет. Цены — **с НДС, целые ₪, за весь заказ** (не за книжку).

| Ключ | Значение | Смысл |
|---|---|---|
| `Types.A5.Quantities` | 1, 2, 4, 10, 20 | разрешённые количества книжек |
| `Types.A5.Price3` | 90, 145, 240, 380, 520 | цена за 3 листа в комплекте, по порядку количеств |
| `Types.Sixes.Quantities` | 1, 2, 5, 10 | |
| `Types.Sixes.Price3` | 145, 240, 420, 620 | |
| `TwoCopiesFactor` | 0,8 | 2 листа = цена 3 листов − 20 % |
| `SetsPerBook` | 50 | только для текстов |
| `LeadTimeDays` | 3 | «до 3 рабочих дней» |
| `VatRate` | 0,18 | цены уже с НДС; нужен только если сервер отдаёт цену без НДС |

Расчёт:
1. `P3 = Price3[i]`, где `i` — индекс `Quantity` в `Quantities` выбранного вида.
2. 3 листа: `Total = P3`. 2 листа: `Total = round(P3 × TwoCopiesFactor; 0)`, `MidpointRounding.AwayFromZero`, `decimal`.
3. Минимального заказа отдельно нет: минимум = самая дешёвая ячейка (A5, 2 листа, 1 книжка = 72 ₪).

## 3. Страница

- URL: `/pinkasim` (иврит) и `/ru/pinkasim` (русский). Сюда ведут плитка на главной (`Pages/Index.cshtml`, сейчас `href="#"`), ссылка в футере (`_Footer.cshtml`, сейчас `#`) и пункт меню ☰ «Бухгалтерские книжки» / «פנקסים» после «Каталоги».
- Хлебные крошки «Главная / Бухгалтерские книжки», заголовок и подзаголовок из §8.
- Переключатель вида: две кнопки-вкладки «A5» и «Шестёрки (6 на A4)» (радиогруппа, клавиатура стрелками). Под ним таблица цен выбранного вида: строки — количество книжек, столбцы «3 листа» и «2 листа».
- Клик по ячейке (или Enter/Space на ней) выбирает количество и число листов; выбранная ячейка и строка подсвечены. По умолчанию: **A5, 3 листа, 4 книжки (240 ₪)**. При смене вида количество сбрасывается на ближайшее разрешённое не больше текущего (A5 4 → «шестёрки» 2), число листов сохраняется.
- Блок «Ваш заказ»: сводка («A5 · 3 листа · 4 книжки по 50 комплектов»), итог `240 ₪` с подписью «вкл. НДС» (целые ₪, **строки НДС нет**), срок «до 3 рабочих дней», кнопка «Заказать в WhatsApp», ссылка «Вопрос? Напишите в WhatsApp». Итог в `aria-live="polite"`.
- Цену показывает сервер: при каждом выборе запрос `?handler=Calculate` (§4); пока ждём ответ, итог приглушён и кнопка заказа неактивна; старый ответ не перезаписывает новый. Таблица на странице выводится сервером из конфига (Razor), в JS цен нет.
- Телефон (до 768 px): блок заказа над таблицей, снизу закреплённая панель «Итого … Заказать →» (параметр страницы в `_BottomBar`, не жёстко `/stickers`), `scroll-padding-bottom` не меньше высоты панели.
- Кнопка «Назад» браузера: выбор (вид, листы, количество) сохраняется в `sessionStorage` и восстанавливается при загрузке и на `pageshow`, значения проверяются по конфигу; `sessionStorage` в `try/catch`.
- Блоки «Что входит» (список §1), «Требования к макету» (§6), «Получение и оплата», «Что происходит после заказа» (4 шага). Тексты — §8.
- Картинка: `wwwroot/img/receipt-books.jpg` (уже есть), alt на обоих языках.
- SEO: `meta_title`, `meta_description` на двух языках (§8).

## 4. API

`POST /pinkasim?handler=Calculate` (antiforgery, как `Catalogs.cshtml.cs`). Поля формы:

| Поле | Значения |
|---|---|
| `Type` | `A5` \| `Sixes` |
| `Copies` | `2` \| `3` |
| `Quantity` | целое из `Quantities` выбранного вида |

Успех: HTTP 200, `{ "success": true, "data": { "status": "Ready", "priceIncVatIls": 240 }, "wpmessage": "<готовый URL WhatsApp>" }`. `priceIncVatIls` — целое, это и показывают страница и сообщение.

Ошибка (как у наклеек и каталогов): HTTP 200, `{ "success": false, "data": { "status": "ValidationError", "errorCode": "…" } }`, цены и `wpmessage` нет. Проверки в этом порядке, возвращается первый код:

1. `qty_int` — количество пустое, не число или дробное;
2. `bad_type` — вид отсутствует или не `A5`/`Sixes`;
3. `bad_copies` — листов нет или не 2/3;
4. `qty_not_allowed` — целое, но нет в `Quantities` выбранного вида (в т. ч. 0 и отрицательные).

Любое значение не из списка — ошибка, а не значение по умолчанию. Лишние поля (в том числе цена из браузера) игнорируются. HTTP 500 на любом вводе недопустим.

Тексты ошибок (resx). На странице они почти невозможны (выбор только кликом по таблице), поэтому одна строка под таблицей:
- ru: «Не удалось рассчитать цену. Выберите вариант в таблице или напишите нам в WhatsApp.»
- he: «לא הצלחנו לחשב מחיר. בחרו אפשרות בטבלה או כתבו לנו ב-WhatsApp.»

Сервис — отдельный класс `PinkasimPriceService` (singleton) с юнит-тестами T01–T10 и V01–V09. `OrderType.Pinkasim` в `Utils/Helpers.cs`.

## 5. Сообщение WhatsApp

Собирает сервер: общая константа `WHATSAPP_URL` + `Uri.EscapeDataString(текст)`. Цена целыми ₪, в иврите число с ₪ обёрнуто в LRM. Строки НДС и кода заказа нет. Строка «Начальный номер» всегда есть, клиент дописывает номер сам.

```text
Здравствуйте! Хочу заказать бухгалтерские книжки.
Вид: A5
Листов в комплекте: 3 (белый, розовый, жёлтый)
Количество: 4 книжки по 50 комплектов
Цена: 240 ₪ с НДС
Начальный номер: 
Файл макета пришлю следом через 📎 → «Документ» (не «Галерея»). Если макета нет, пришлю логотип и реквизиты.
```

```text
שלום! אני רוצה להזמין פנקסים.
סוג: A5
עותקים בסט: 3 (לבן, ורוד, צהוב)
כמות: 4 פנקסים, 50 סטים בכל פנקס
מחיר: 240 ₪ כולל מע״מ
מספר התחלתי: 
את קובץ ההדפסה אשלח מיד דרך 📎 ← "מסמך" (לא "גלריה"). אם אין קובץ, אשלח לוגו ופרטי העסק.
```

Варианты строк: вид «Шестёрки (6 на A4, бланк 10,5 × 9,9 см)» / «שישיות (6 בדף A4, טופס 10.5×9.9 ס״מ)»; 2 листа «2 (белый, жёлтый)» / «2 (לבן, צהוב)». Количество по-русски склоняется: 1 книжка, 2/4 книжки, 5/10/20 книжек; на иврите 1 «פנקס אחד», иначе «{n} פנקסים».

## 6. Требования к макету

- Свой файл: PDF, PNG или JPEG, до 100 МБ, 300 dpi, в размер бланка (A5: 148 × 210 мм; «шестёрка»: 105 × 99 мм), чёрно-белый (цвет печатается оттенками серого).
- Место для номера и перфорации проверим и подгоним при подготовке к печати.
- Нет файла: пришлите логотип и реквизиты (название, ч.п./ח.פ., адрес, телефон), сверстаем бесплатно.

## 9. Технические требования (уроки визиток и каталогов)

1. Цена и проверка только на сервере; JS в `wwwroot/js/pinkasim.js`, без inline-скриптов (CSP), тексты через `data-*`.
2. Все тексты в `Resources/Pages/Pinkasim.{he,ru}.resx`, без заглушек в квадратных скобках.
3. Числа в форме и в API — инвариантная культура, на `/ru` тоже.
4. Ссылка WhatsApp — общая константа, без фигурных скобок вокруг номера (ошибка визиток).
5. Сборка без предупреждений, юнит-тесты зелёные.

## 10. Чего нет в этой версии

25 комплектов, цветная печать, 4 листа в комплекте, своё количество книжек, другие форматы, доставка, оплата и загрузка файла на сайте, поле стартового номера.
