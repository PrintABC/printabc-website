## Б2. Сломанная ссылка WhatsApp

**Было.** В resx шаблон с ручными `%0a` и `%0📎`: `%0` без второй цифры — это сломанный код, браузер не может прочитать
ссылку. Нет строки «Начальный номер», конец сообщения обрезан.

**Стало.** В resx — обычный текст, каждая строка сообщения своим ключом (`msg_hello`, `msg_kind`, … `msg_file`).
В `{0}` подставляется значение. JS соединяет строки через `'\n'` и кодирует всё одним вызовом `encodeURIComponent`:

```js
var msg = [t.msg_hello, fill(t.msg_kind, ...), ..., t.msg_start, t.msg_file].join('\n');
next.href = waUrl + encodeURIComponent(msg);   // '\n' сам станет %0A, иврит и 📎 — правильными кодами
```

Правило на будущее: **в текстах никогда не писать `%0a`, `%20` и т. п. руками** — кодирует только `encodeURIComponent`
(в JS) или `Uri.EscapeDataString` (в C#).

В иврите число с ₪ обёрнуто в LRM (невидимый символ «слева направо»), иначе «240 ₪» в тексте справа налево
может стать «₪ 240». Символ берётся из `t.lrm`, в русском он пустой.

**Проверка.** Нажать «Заказать в WhatsApp» → текст совпадает с ТЗ §5 на обоих языках, есть строка «Начальный номер: ».

## Б5. Нижняя панель вела на наклейки

**Было.** `_BottomBar.cshtml` всегда показывал «Рассчитать цену наклеек».

**Стало.** Страница сама выбирает вид панели строкой в своём `.cshtml`:

```cshtml
ViewData["BottomBar"] = "order";   // в Pinkasim.cshtml
```

`_BottomBar.cshtml` читает `ViewData["BottomBar"]`. Если там `"order"`, то показывает «Итого — ₪ · Заказать →»
(разметка из макета, `data-bar-total`, `data-bar-ok`). Иначе — старую кнопку наклеек, поэтому другие страницы не меняются.
Итог и ссылку в панели заполняет `pinkasim.js` — ту же ссылку, что у большой кнопки.

Почему не `@model` в partial: если модель `null`, ASP.NET передаёт в partial модель страницы, и `@model string`
падает с ошибкой типа. `ViewData` общий у страницы и partial-ов, так проще и надёжнее.

Ещё в `layout.css` добавлен `scroll-padding-bottom` на высоту панели: при переходе по Tab поле не прячется под панелью.

**Проверка.** Телефон 390 px → внизу «Итого 240 ₪ · Заказать →», ссылка = ссылка кнопки WhatsApp. На /stickers — как раньше.

## В5. Inline-скрипт → `wwwroot/js/pinkasim.js`

**Было.** ~130 строк JS прямо в `.cshtml`. Когда включат CSP (защиту от чужих скриптов), страница перестанет работать.

**Стало.** Файл подключается так:

```cshtml
<script src="~/js/pinkasim.js" asp-append-version="true" defer></script>
```

Тексты для JS страница кладёт в JSON-блок, его `main.js` уже умеет читать в `window.PRINTABC.t`:

```cshtml
<script type="application/json" id="page-strings">@Json.Serialize(strings)</script>
```

`type="application/json"` — это данные, браузер их не выполняет, CSP такой блок не запрещает.
Адрес WhatsApp передаётся атрибутом `data-wa-url` на `#pk-calc`.

## В2. «4 Книжек» в сводке

**Было.** `число + "Книжек, 50 комплектов в книжке"`.

**Стало.** Склоняет сервер — функция `PinkasimModel.BooksText`: 1 книжка, 2–4 книжки, 5–20 книжек; в иврите
«פנקס אחד» / «{n} פנקסים». Готовый текст кладётся в `data-books` у каждой строки таблицы, JS просто его берёт.
Так склонение написано один раз и в одном месте.

Важная мелочь в `BooksText`: строка с `{0}` берётся через `L.GetString(key, n).Value`.
`L[key, n].Value` вернул бы текст **без** подстановки числа.

**Проверка.** «A5 · 3 листа · 4 книжки по 50 комплектов»; шестёрки 10 → «10 книжек»; иврит 1 → «פנקס אחד».

## В3 + М1 + М2. Иврит в aria-label на /ru, заголовок столбца, имена атрибутов

18 кнопок теперь рисуются циклом из `PinkasimModel.Kinds`. `aria-label` собирается из ресурсов:
на /ru «1 книжка · 3 листа · 90 ₪», на иврите «פנקס אחד · 3 עותקים · 90 ₪».

Атрибуты как в макете: `data-kind-name`, `data-summary`, `data-error` (вместо `pk-kind-name`, `pk-sum-*`).
«A5» в разметке — тоже из ресурса `kind_a5`.

Цены по-прежнему в `data-price` (ТЗ v1.1). Чтобы поменять цену — одно число в `Pinkasim.cshtml.cs`.

## В1. «Назад» не возвращал выбор

Выбор `{kind, copies, q}` сохраняется в `sessionStorage` при каждом изменении. При загрузке и на событии `pageshow`
(когда браузер достаёт страницу из кэша по «Назад») он читается обратно. Перед использованием проверяется, что такая
кнопка есть в таблице (`valid`). Иначе остаётся выбор по умолчанию. `store.get/set` из `main.js` не падают в приватном режиме.

**Проверка.** Шестёрки · 2 листа · 10 → уйти на главную → «Назад» → снова шестёрки · 2 · 10, 496 ₪.
