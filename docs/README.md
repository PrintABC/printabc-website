# Документация PrintABC: ТЗ, задания, проверки

Здесь лежит всё, что нужно разработчику по каждой странице. Файлы больше не пересылаются: актуальная версия — в этой папке, история изменений — в git.

## Структура

| Папка | Что внутри |
|---|---|
| `stickers/` | Наклейки: ссылка на ТЗ калькулятора, `tests.json` |
| `business-cards/` | Визитки: `tz.md`, варианты текста WhatsApp |
| `catalogs/` | Каталоги и журналы: `tz.md`, `tests.json`, `dev/` — задания с готовыми патчами |
| `pinkasim/` | Бухгалтерские книжки: `tz.md` (черновик) |
| `whatsapp-order/` | Общий модуль «Заказать в WhatsApp»: `tz.md` (v2.2) |
| `tests/` | `price_tests.py` — проверка цен сайта против ТЗ |
| `reviews/` | Отчёты проверок: `<дата>-<страница>-<вид>.md` |

## Правила

- **ТЗ меняет только владелец** (через PR с изменением `tz.md`). Версия и дата — в начале файла.
- **Задание разработчику** = PR с кодом (ветка `claude/...`) или GitHub Issue со ссылкой на раздел ТЗ. Задание закрыто, когда PR смержен.
- **Вопрос по ТЗ** — Issue с меткой страницы; ответ владельца вносится в `tz.md`.
- **Контрольные цены** (`tests.json`) меняются только вместе с ТЗ.
- **Проверка цен:** `python3 docs/tests/price_tests.py --base http://localhost:5000 docs/catalogs/tests.json` (по умолчанию — тестовый сайт).
- Скриншоты к отчётам в репозиторий не кладутся; пометка «(внутренний файл, в репозитории нет)» — файл у владельца.
