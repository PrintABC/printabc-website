## 1. Продукт

- Ролл-ап стенд в комплекте: **стенд + напечатанное полотно + сумка**. Один вид, других товаров на странице нет.
- Размер один: **85 × 200 см**.
- Полотно: **полипропилен**, цветная печать, **одна сторона**.
- Отдельная замена полотна, другие размеры, двусторонние стенды — нет.
- Дизайна нет: клиент присылает **готовый файл** в WhatsApp (§6).
- Количество на сайте: **1, 2 или 3 шт.** Больше 3 — по запросу в WhatsApp, на сайте не считается.
- Срок: **до 3 рабочих дней**.
- Получение: **только самовывоз**, ул. Штампфер 5, Нетания, бесплатно. Доставки нет.
- Оплата вне сайта, при получении: наличные, карта, Bit или перевод.

## 2. Цены (единственный источник значений)

Значения — в разметке страницы: `data-price` = итог у каждой кнопки количества; цена за шт. — текст на кнопке (§8 `qty_unit`), JS её не читает. Цены — **с НДС, целые ₪**. Расчёта нет: итог = `data-price` выбранной кнопки.

## 6. Требования к файлу

- PDF в размер полотна **85 × 200 см**, разрешение от **150 dpi в полный размер** (≈ 5000 × 11 800 px).
- Вылет (bleed) **3 мм** с каждой стороны: файл **856 × 2006 мм**.
- Нижние **10 см** без текста — уходят в кассету стенда.
- Текст и логотип — не ближе **3 см** к боковым и верхнему краю.
- Печать одной стороны, цветная.
- Файла нет — сайт дизайн не делает; вопрос можно задать в WhatsApp.

## 9. Технические требования

1. Цена в браузере; JS inline в `Rollup.cshtml`, тексты из resx через `@Json.Serialize`, в самом JS слов нет.
2. `RollupModel` пустой; все тексты в `Resources/Pages/Rollup.{he,ru}.resx`, без заглушек в квадратных скобках.
3. Числа в `data-*` — инвариантная культура, на `/ru` тоже.
4. Ссылка WhatsApp — общая `WHATSAPP_URL` (api.whatsapp.com), без фигурных скобок вокруг номера.
5. Сборка без предупреждений.
6. Стили страницы — в `wwwroot/css/pages.css` (блок из макета v1.0.1), без `style=""`; у `<img>` есть `width`/`height`.
