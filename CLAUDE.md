# CLAUDE.md — правила проекта PrintABC website

Этот файл читают AI-агенты (Claude), которые пишут или проверяют код в этом репозитории,
и программист. Если код нарушает правило — это замечание в ревью.

## Контекст

- Сайт типографии PrintABC (Нетания, Израиль). Языки: **иврит (основной, RTL)** и **русский (LTR)**.
- Стек: ASP.NET Core (.NET 10), Razor Pages, Minimal API, EF Core, PostgreSQL. **Без React, Node, npm.**
- Эталон дизайна — `design/mockup/`. Разметка, классы, CSS и JS переносятся оттуда.

## 1. Дизайн и CSS

1. CSS-файлы из `design/mockup/assets/css` копируются в `wwwroot/css` и подключаются в порядке:
   `tokens.css → base.css → components.css → layout.css → pages.css`. Порядок не менять.
2. **Запрещено:** атрибут `style="…"`, цвета/шрифты/отступы вне `tokens.css`, Bootstrap/Tailwind и любые CSS-фреймворки.
3. Имена классов, `id`, `data-*` и `aria-*` из макета **не переименовывать** — на них завязаны CSS и JS.
4. Новые стили — в подходящий из 5 файлов, именование `.block__part--modifier`.
5. RTL — только логические свойства: `margin-inline-start`, `padding-inline-end`, `inset-inline-*`.
   `left/right`, `margin-left/right`, `text-align: left/right` — запрещены (кроме `.ltr`).
6. Мобильная версия — **только CSS** (`@media (max-width: 767.98px)`). Никаких `isMobile`, проверок User-Agent
   и отдельных мобильных страниц.

## 2. Разметка и языки

1. Один `.cshtml` на страницу для обоих языков. Весь видимый текст — через `@L["ключ"]`
   (`IHtmlLocalizer<SharedResource>`), ключи — как в `design/strings` / resx. Текст в разметке не хардкодить.
2. `<html lang dir>` выставляется в `_Layout` из текущей культуры. Иврит — без префикса URL, русский — `/ru/…`
   (или `/he/` и `/ru/` — как утверждено в документе; не смешивать).
3. Телефоны, часы, годы в иврите — в `<bdi dir="ltr">` или `.ltr`. Поля телефона и e-mail — `dir="ltr"`.
4. Каждая страница: свои `title`, `description`, `hreflang` (he, ru, x-default).

## 3. Доступность (IS 5568 / WCAG 2.0 AA — требование закона)

- Skip-link, видимый фокус, `label for` у каждого поля, `fieldset/legend` у групп, настоящая `<table>` для цен.
- Ошибки форм: текст рядом с полем, `aria-invalid`, `aria-describedby`, фокус на первое ошибочное поле.
- Иконки — `aria-hidden="true"`; кнопки-иконки — с `aria-label`.

## 4. Серверная логика

1. **Сервер — единственный источник цен.** Сумма заказа всегда пересчитывается на сервере по параметрам;
   цена из браузера не принимается.
2. Бизнес-логика — в сервисах (`Pricing/`, `Orders/`), не в PageModel и не в эндпоинтах.
3. Лимиты наклеек: размер 1×1 … 31,5×46 см (поворот допустим), круг Ø ≤ 31,5 см; тираж — целое ≥ 1;
   сумма заказа 60–1000 ₪ с НДС 18 %. Получение — только самовывоз. Оплаты на сайте нет.
4. Файл заказа: PDF/PNG/JPEG по сигнатуре, ≤ 100 МБ, хранится вне `wwwroot`, имя = номер заказа + GUID.
5. Секреты — только из переменных окружения / user-secrets. Никаких паролей и ключей в репозитории.
6. Антиспам: rate limiting на `/api/orders`, honeypot, antiforgery.

## 5. Скорость на телефоне

- Фото — WebP в нескольких размерах (`srcset`/`<picture>`), с `width`/`height`; LCP-фото без lazy, остальные `loading="lazy"`.
- Шрифты — woff2 со своего сервера, `font-display: swap`, preload только основных.
- Цель Lighthouse (mobile, slow 4G): Performance ≥ 90, Accessibility ≥ 95, SEO ≥ 95, LCP ≤ 2,5 с, CLS ≤ 0,1.

## 6. Процесс

- Изменения только через Pull Request в `main`. Одна задача — один PR, понятное описание + скриншоты he/ru × 390/1440 px.
- Перед PR: `dotnet build` без предупреждений, `dotnet test` зелёный.
- Коммиты — на английском, в повелительном наклонении (`Add stickers calculator API`).

## Чек-лист ревью (для агента)

При проверке PR ответить по каждому пункту: ✅ / ❌ + где именно.

1. Нет `style=""` и цветов вне `tokens.css`?
2. Классы/id/data-* совпадают с `design/mockup`?
3. Только логические CSS-свойства, RTL не сломан?
4. Тексты через локализацию, оба языка заполнены?
5. Доступность: label, aria, фокус, ошибки?
6. Цена считается на сервере, лимиты соблюдены?
7. Нет секретов в коде?
8. Есть тесты на новую логику?
9. Визуально совпадает с эталоном (по скриншотам из PR)?
