# PrintABC — статическая вёрстка (HTML + общие CSS/JS)

Открыть: `index.html` → редирект на `he/index.html`. Лучше через локальный сервер:
`python3 -m http.server -d .` → http://localhost:8000

## Структура
```
he/  ru/                 по 4 страницы: index, stickers, business-cards, order
assets/css/
  tokens.css             цвета, шрифты, размеры, отступы, радиусы (меняются в одном месте)
  base.css               reset, типографика, фокус, утилиты, режимы доступности
  components.css         кнопки, pills (радио), поля форм, ошибки, плитки, бейджи, шаги…
  layout.css             шапка, мобильное меню, панель доступности, футер, WhatsApp, нижняя панель
  pages.css              секции страниц (главная, продукт, заказ)
assets/js/
  main.js                меню, панель доступности (localStorage), общие строки
  calculator.js          калькулятор наклеек (демо-формула → заменить на API)
  cards.js               таблица цен визиток
  order.js               форма заказа: сводка, файл, валидация, экран «готово» (?done=1)
assets/img, assets/icons фото и SVG-иконки
```

## Принципы
- **Ни одного inline-стиля.** Все страницы подключают одни и те же 5 CSS-файлов в этом порядке.
- **Один HTML для мобильной и десктопной версии.** Различия — только в CSS: `@media (max-width: 767.98px)`
  в конце `layout.css` и `pages.css` (бургер-меню, нижняя панель, 2 колонки товаров, калькулятор первым).
- **RTL/LTR:** `<html dir="rtl">` для иврита, `dir="ltr"` для русского; в CSS — логические свойства
  (`margin-inline`, `inset-inline-end`), поэтому отдельного RTL-файла нет.
- Шрифт текста выбирается по `:lang(ru)`; заголовки — Rubik.
- Классы — по смыслу (`.btn--primary`, `.tile`, `.site-header`), похоже на BEM.
- Доступность: skip-link, видимый фокус, `fieldset/legend`, настоящая `<table>`, `aria-invalid` + текст ошибки.

## Передача данных между страницами
Калькулятор/таблица пишут выбор в `sessionStorage['printabc-order']` → `order.html` показывает сводку.
Запасной вариант: `order.html?product=stickers|cards`.

## Что подключить на бэкенде
- Цены: заменить демо-формулу в `calculator.js` и `data-price` в `business-cards.html`.
- Отправка заказа: `order.js` → место помечено `TODO backend`.
- Карта Google: в `index.html` заготовка iframe в комментарии.
- Ссылки `href="#"` — страницы, которых пока нет (категории, условия, политика, заявление о доступности).
- Шрифты Google Fonts подключены в `<head>`; при желании — локально.

`_generator/build.py` — скрипт, которым собраны страницы из текстов (необязателен для разработчика).
